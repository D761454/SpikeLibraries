# Security Policy

Each library within SpikeLibraries are primarily designed for developer tools and technical applications running trusted code and trusted data.

Each library within SpikeLibraries was developed with a focus on developer experience, usability,  
and robustness in real-world applications. We will do our best to reduce issues with the libraries where we can.

However, as the libraries have differing use-cases, where maintenance of one or the creation of a new library may be underway at any time, 
the libraries do not focus on highly artificial edge cases unlikely to occur in most scenarios.

## Reporting a Vulnerability

Considering the above policy, most things may be reported in GitHub Issues, ideally using the provided templates. 
If you have a reason to disclose an issue privately, please reach out to the contact address listed in the README or on my profile.

You may not receive updates on reported vulnerabilities frequently, but be sure they will be looked into and worked on.
